# Tilt to Live — 鼠标版

一个用鼠标玩的高还原度 **Tilt to Live** 致敬版（单文件 HTML5 游戏）。
原版是 2010 年 One Man Left 出品的 iOS 经典（Metacritic 90 分），用设备倾斜控制小箭头躲避红点。本作把"倾斜"映射到**鼠标移动**，让你在电脑上重温手感。

## 怎么玩

**双击打开 `tilt.html` 即可开始**（推荐 Chrome / Edge 浏览器），无需安装任何东西。

| 操作 | 说明 |
|------|------|
| 🖱 移动鼠标 | 控制箭头方向——箭头会带着惯性"滑"向鼠标，这就是倾斜手感 |
| 鼠标移出窗口 | 箭头保持最后方向继续加速（模拟持续倾斜） |
| 点击 / 空格 / 回车 | 开始游戏、再来一局 |
| R | 重新开始 |
| P | 暂停 / 继续 |
| M | 静音 / 取消静音 |

## 玩法

- 🔴 **红点**是敌人，会追踪你，碰到就死（撞红点那一下判定很宽容，还原原版手感）
- 🟢 **绿点**是分数，吃一个 +1 分；**累计绿点还能解锁新武器**
- 🛰 **武器球**（场上同时 3 个，收一个刷一个）是核心道具——收集后立即释放：

| 武器 | 解锁条件 | 效果 | 使用奖励分 |
|------|---------|------|-----------|
| ☢ 核弹 Nuke | 初始 | 以玩家为中心大爆炸，清掉周围红点 | +3 |
| ≫ 冲击波 Wave | 初始 | 蓄力后朝面朝方向张开扇形冲击波，扫掉扇形内红点 | +5 |
| ➶ 导弹 Missiles | 初始 | 发射 7 枚自动追踪红点的导弹 | +10 |
| ❄ 冰爆 Ice Blast | 20 绿点 | 冻住周围红点，撞碎它们 | +8 |
| ◌ 泡泡护盾 Bubble Shield | 40 绿点 | 护盾挡下一次撞击并爆炸，第二条命 | +10 |
| ◎ 漩涡 Vortex | 70 绿点 | 扔出黑洞，吸走附近红点（小心自己也被吸） | +10 |
| ✸ 刺球 Spike Shield | 90 绿点 | 变成大刺球 6 秒无敌，红点吓得逃跑 | +10 |
| ⚡ 闪电 Lightning | 120 绿点 | 4 秒无敌，持续电击红点并连锁传导 | +6 |
| 🔥 烈焰战车 Burnicade | 240 绿点 | 瞄准后冲刺，身后留下一道烧红点的火墙 | +2000 |
| ◉ 炮塔 Turret | 300 绿点 | 变成炮台 6 秒，向鼠标方向扫射 | +3 |

- **连击**：1.5 秒内连续击杀红点，连击数 xN 会累加；连击中断时结算 **N×N×6** 分（原版规则）——连杀越多越赚
- 击杀红点 +10 分；难度随时间上升（红点越来越多、越来越快，40 秒后出现快速小红点，80 秒后出现慢速大灰点）
- 最高分会保存在浏览器里（本地记录）

## 与原版（iOS 1 代）的差异说明

做这个版本前，我联网收集了原版资料（Fandom 官方 Wiki 的 26 个页面、Wikipedia、App Store 官方介绍、Metacritic 评价），以下是考证结论与本作取舍：

- **原版没有绿点**：1 代的收集物只有武器球（Orbs），得分主要靠击杀红点 + 连击。**绿色小点收集其实是《Tilt to Live 2》的机制**（2013 年）。本作把两代融合：保留 1 代的武器球系统与连击计分，同时加入绿点收集（绿点数直接作为武器解锁货币）。这样既还原 1 代手感，也满足"收集绿点增强武器"的直觉。
- **武器解锁门槛**沿用 Fandom Wiki 记载的 award points 数值（20/40/70/90/120/240），本作以绿点计数替代。
- **手感差异**：原版靠重力感应持续施力，鼠标版用"箭头朝鼠标加速 + 惯性 + 靠近鼠标刹车"模拟；鼠标比倾斜更精确，所以初始难度略高于原版前 30 秒。
- 原版的 6 种模式（Classic / Code Red / Gauntlet / Frostbite / Viva la Turret）本作先实现 **Classic 经典模式**，其余模式与 BGM 后续可加。

## 开发者小抄（调参数）

所有手感/难度参数集中在 `tilt.html` 顶部的 `CFG` 对象里，改数值即可：

```js
playerAccel: 1750,      // 加速度——越大箭头越"冲"
playerMaxSpeed: 430,    // 最高速度
playerDamping: 0.9,     // 阻尼——越大滑行越短
spawnRateBase: 0.9,     // 红点初始生成率（个/秒）
dotSpeedBase: 115,      // 红点初始速度
comboWindow: 1.5,       // 连击窗口（秒）
greenTarget: 15,        // 场上绿点数量
```

想改武器解锁门槛，改 `UNLOCKS` 数组里的 `need` 值。

## 代码结构导读（约 1000 行，中文注释）

```
tilt.html
├── 配置区      CFG 手感参数 + UNLOCKS 武器解锁表 + WEAPONS 武器数据
├── 工具函数    rand / clamp / dist2 …
├── 音效        Web Audio 合成（无外部文件）
├── 实体        红点 / 绿点 / 武器球 / 粒子 / 冲击波 / 飘字
├── 武器逻辑    useWeapon() —— 10 种武器的开关
├── 更新逻辑    update() —— 物理、追踪、碰撞、生成、特效
├── 渲染        draw() —— 背景、实体、HUD、屏幕特效
└── 状态机      menu → playing → dying → over
```
