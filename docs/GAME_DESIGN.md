# 游戏机制设计文档（GAME DESIGN）

> 本文件记录游戏的全部机制规格与数值，是"游戏应该长什么样"的权威描述。
> 资料来源：[Fandom Tilt to Live Wiki](https://tilttolive.fandom.com/)（26 个页面）、
> Wikipedia、App Store 官方描述（2010 年版）、Metacritic。考证结论与取舍见 README「与原版的差异说明」。

## 1. 设计目标

1. 在 PC 上还原原版《Tilt to Live》（2010，One Man Left）的核心体验：**惯性滑动 + 躲避 + 武器清场**
2. 把"设备倾斜"映射为"鼠标移动"，保持原版"滑"的手感而非瞬移
3. 融合玩家记忆中的绿点收集机制（实为 Tilt to Live 2 的机制），绿点同时作为武器解锁货币
4. 单文件、零依赖、打开即玩

## 2. 核心循环（Core Loop）

```
移动鼠标 → 箭头惯性滑向鼠标
  ├─ 躲避红点（碰到即死，护盾/无敌可挡）
  ├─ 收集绿点（+1 分，累计解锁武器）
  └─ 收集武器球（3 个在场）→ 释放武器清场 → 连击暴涨
难度随时间上升（红点更多更快）→ 死亡 → 结算分数/最高分 → 再来一局
```

## 3. 数值规格

### 3.1 玩家

| 参数 | 值 | 说明 |
|------|----|------|
| 加速度 `playerAccel` | 1750 px/s² | 朝鼠标方向的加速度 |
| 最大速度 `playerMaxSpeed` | 430 px/s | 速度上限 |
| 阻尼 `playerDamping` | 0.9 | 速度每帧乘 `exp(-0.9×dt)` |
| 碰撞半径 `playerRadius` | 9 px | 故意偏小（宽容判定，还原原版手感） |
| 刹车区 `mouseStopDist` | 60 px | 距鼠标 60px 内开始刹车，停稳在鼠标附近 |

### 3.2 红点敌人

| 类型 | 半径 | 速度 | 出现时机 |
|------|------|------|---------|
| 普通红点 | 11 px | `min(115 + t×0.45, 180)` | 开局即有 |
| 快速小红点 | 7 px | 210 px/s | t > 40s，20% 概率 |
| 慢速大灰点 | 17 px | 62 px/s | t > 80s，12% 概率 |

生成率：`min(0.9 + t×0.045, 6.5)` 个/秒（t = 存活秒数），场上上限 450。
追踪行为：朝玩家直线逼近 + 正弦摆动（幅度 0.35），红点互碰对半分推。

### 3.3 绿点

| 参数 | 值 |
|------|----|
| 场上数量 | 维持 15 个（收集后立即补刷） |
| 半径 | 5 px |
| 收集距离 | 22 px |
| 分值 | +1 分/个 |

### 3.4 计分公式

| 事件 | 得分 |
|------|------|
| 收集绿点 | +1 |
| 击杀红点 | +10 |
| 连击结算（中断时一次性入账） | **combo² × 6** |
| 使用武器 | 见下表（Nuke +3 / Wave +5 / Lightning +6 / Ice +8 / Missiles +10 / Vortex +10 / Bubble +10 / Spike +10 / Turret +3 / **Burnicade +2000**） |

连击规则：击杀间隔 ≤ 1.5s 视为连击；HUD 显示 xN，连击 ≥ 5 时结算有飘字演出。
连击成就参考（原版数据）：x200 = "难以置信的连击"，x42 = "生命宇宙一切的答案"。

### 3.5 武器系统（10 种）

| 武器 | 解锁（绿点） | 奖励分 | 释放效果与参数 |
|------|------------|--------|---------------|
| ☢ 核弹 Nuke | 初始 | +3 | 半径 300 爆炸清场；震屏 22 + 白闪 |
| ≫ 冲击波 Wave | 初始 | +5 | 0.5s 蓄力（减速），沿移动方向射冲击波，46px 判定宽，速度 720 |
| ➶ 导弹 Missiles | 初始 | +10 | 7 枚环绕发射，追踪最近红点，速度 300→锁定加速，寿命 3.5s，命中爆炸半径 80 |
| ❄ 冰爆 Ice Blast | 20 | +8 | 半径 200 冻结 5s；被冻红点静止，玩家撞碎 +10（不重置连击） |
| ◌ 泡泡护盾 Bubble Shield | 40 | +10 | 套盾；被碰时消耗护盾 + 半径 220 爆炸；已有盾再吃无效 |
| ◎ 漩涡 Vortex | 70 | +10 | 抛向鼠标方向 110px 处，3s 倒计时后激活 8s；半径 300 吸力 420，吸入（<26px）即灭；对玩家有轻微吸引（风险设计） |
| ✸ 刺球 Spike Shield | 90 | +10 | 6s 无敌变刺球，碰到的红点被碾碎；红点反向逃跑（1.15× 速度）；结束前 1.2s 闪红 3 次提示 |
| ⚡ 闪电 Lightning | 120 | +6 | 4s 无敌；每 0.28s 电击半径 190 内 4 个红点（瞬杀），被电点 90px 内连锁传导；屏幕静电特效 |
| 🔥 烈焰战车 Burnicade | 240 | **+2000** | 0.8s 瞄准（方向指示）→ 1.1s 高速冲刺（950 px/s）+ 身后 4s 火墙（半径 18，碰即死）；冲刺时前方 80px 内红点直接被烧 |
| ◉ 炮塔 Turret | 300 | +3 | 6s 无敌变炮塔；每 0.12s 朝鼠标方向射子弹（640 px/s，命中爆炸半径 70） |

设计要点：
- 初始 3 种武器保证新手前 40 秒有保命手段
- 解锁门槛按原版 award points 数值等比映射到绿点
- 高风险武器（Vortex 自吸、Burnicade 直线冲锋）高收益，制造决策空间

## 4. 难度设计

阶段划分（以存活时间 t 为轴）：

| 阶段 | 时间 | 威胁构成 |
|------|------|---------|
| 上手期 | 0–30s | 普通红点为主，生成率 0.9→2.3/s，足够熟悉操作 |
| 压力期 | 30–60s | 生成率 →3.6/s，速度 →142，开始需要武器管理 |
| 快节奏 | 60–90s | 快速小红点出现，需要预判走位 |
| 后期 | 90s+ | 大灰点挤压空间 + 高生成率，武器连发是唯一活路 |

## 5. 控制方案（鼠标 = 倾斜）

原版映射：设备倾斜角 → 重力方向 → 箭头持续受力。
本作映射：**鼠标位置 → 目标方向 → 箭头持续加速滑向鼠标**。

| 原版 | 本作 |
|------|------|
| 倾斜角度 | 鼠标相对箭头的位置方向 |
| 持续施力 | 恒定加速度（1750） |
| 松开设备 | 鼠标移出窗口 → 保持最后方向惯性滑行 |
| 灵敏度校准 | CFG 调参（playerAccel / playerDamping / mouseStopDist） |

已知取舍：鼠标比倾斜精确得多，所以本作难度峰值（6.5/s）低于原版 Code Red（8.5–9.5/s），
且碰撞判定更宽松（玩家半径 9 vs 红点半径 11）。

## 6. 与原版（iOS 1 代）对照表

| 维度 | 原版 | 本作 |
|------|------|------|
| 收集物 | 仅武器球（3 个在场） | 武器球（3 个）+ 绿点（15 个） |
| 得分 | 击杀 10 分 + 武器奖励 + 连击 | 同左 + 绿点 1 分 |
| 连击公式 | n×n×6（Fandom 考证） | 同 |
| 武器 | 10 种，award points 解锁 | 10 种同名单，绿点解锁（数值等比映射） |
| 模式 | 6 种（Classic/Code Red/Gauntlet/Frostbite/Viva la Turret） | Classic（其余预留扩展） |
| 难度 | Code Red 峰值 8.5–9.5 dots/s | 峰值 6.5 dots/s（鼠标精度补偿） |
| 视觉 | 深蓝渐变 + 网格线 | 同（Canvas 实现） |
| 音效 | 版权音乐 + 音效 | Web Audio 合成（无版权问题） |
| 成就 | 46 个 Award Challenges | 死亡结算段子彩蛋（5s 同情/42/200x/60s） |

## 7. 已知问题与后续迭代方向

1. **BGM 缺失**：原版音乐广受好评，本作暂无声乐层（音效已齐）
2. **模式单一**：Code Red（高密度）、Gauntlet（生命条）、Frostbite（低温限制）未实现
3. **手感待实测**：加速度/阻尼/刹车区三个参数是凭资料+经验设定的初值，等待真机反馈校准
4. **敌人队形**：原版红点会组成队形入场（Fandom 提及），本作未实现
5. **成就系统**：完整成就树 + Pocket Points 货币未实现

迭代优先级建议：手感校准 > 模式扩展 > 队形 > BGM > 成就。
