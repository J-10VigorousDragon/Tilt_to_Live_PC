## [v3.5] - 2026-08-03

### 武器（真人实测反馈）

- **Wave 改胶囊形冲击波**：前端为半圆（半径 200）+ 矩形尾端（宽 400px、长 200），整体沿面朝方向以 900px/s 平移直到冲出地图尽头（不再是"飞行的扇子"）。新增 `capHit()` 胶囊命中判定（点投影到中心线、半圆/矩形分段判断），删除原 `fanHit()`。
- **冰冻范围 +15%**：200 → 230（基准值，×scale）。
- **冰冻改放射冰刺特效**：释放时 12 根冰刺从玩家向四周射出（0.35s 伸长动画），不再只是扩散圆环；新增 `G.iceBurst` 特效实体（更新 + 绘制 + 开局重置）。

### 测试

- 修复 `test_smoke.js` 移动断言的随机性缺陷：断言前清空红点并强制 `playing` 状态（原 3 秒游戏可能随机撞红点死亡导致 update 停止、断言误报）。
- 全部通过（冒烟 + 物理验证）。

## [v3.4] - 2026-08-03

### 调整（真人实测反馈）

- **武器球缩小**：`orbRadius` 24→11（与红点同尺寸）、`orbCollectDist` 36→26、符号字体 22→14。
- **Wave 改固定大小月牙形冲击波**：扇形半径固定 = **8 个背景格**（44px×8 = 352px，不随 scale 缩放），波整体沿面朝方向以 900px/s 平移，直到冲出地图对角线 + 半径后消散（不再随推进扩张）。
- **Wave 蓄力停滞大大缩短**：蓄力 0.5s→**0.2s**，蓄力期间减速 0.6→0.85/帧（几乎无停滞感）。
- **红点缩小 20%**：普通 `dotRadius` 11→9、快速 `fastDotRadius` 7→6（大灰点 17 不变）。

### 测试

- `test_smoke.js` / `verify_physics.js` 全部通过（物理手感不受本次调整影响）。

## [v3.3] - 2026-08-02

### 手感（真人实测：太灵活刹不住车，需复刻原版重力体感的温和手感）

- **玩家物理重构为"目标速度控制"（PD 控制）**：箭头"想"以与鼠标距离成正比的速度滑向鼠标（`targetSpeed = min((d - 18) × 7, 350)`，速度以 `playerFollow=5/s` 向目标收敛）。远离时温和加速、靠近时自然减速，**数学上永不冲过头、无振荡**；`playerMaxSpeed` 520→350（温和）。箭头停在鼠标 18px 间隙处，避免被光标遮挡。
- 鼠标移出窗口改为**惯性滑行**（阻尼衰减），模拟"松开倾斜"；删除 v3.1 的磁铁加速度/刹车区/动态刹车逻辑。

### 武器（真人实测：Wave 冲击波范围太小）

- **Wave 扇形冲击波改为全图推进**：从发射点沿面朝方向以 900px/s 持续推进（半径 = 推进距离），直到覆盖整个地图对角线后消散——"一直冲到地图尽头"。

### 尺寸（真人实测：原版为 iPhone 4S 小屏，电脑显示器需等比放大）

- 新增**全局缩放** `scale = max(1, min(W,H) / 600)` 与换算函数 `R()`：红点/绿点/武器球/玩家/箭头/粒子/全部武器半径与判定距离随屏幕等比放大（1080p 下约 1.8×）；速度不缩放（配合温和手感）。网格/HUD 不缩放。

### 测试

- `verify_physics.js` 期望更新为新物理：远端追鼠 4s 至 21px（温和逼近）；高速冲入停在 22px、振荡 1 帧。
- `test_smoke.js` 全绿。

## [v3.2] - 2026-08-02

### 修复（P0：玩家完全无法移动）

- **根因**：v2 迭代在重排阻尼/限速逻辑时**误删了速度积分行 `P.vx += accX * dt; P.vy += accY * dt;`**（见 git diff `e5c9ad1..010bf36` 玩家物理段）。加速度照常计算但从未施加到速度上，箭头仅受阻尼衰减——自 v2 起玩家无法用鼠标控制移动（v3/v3.1 的手感调整均未触及此因，实际都在"无接线"的物理上做优化）。
- **修复**：在阻尼之前补回速度积分行（`tilt.html` 玩家物理段，含注释标记）。
- **测试防护**：`test_smoke.js` 新增**玩家移动断言**（鼠标固定远处、驱动 60 帧、P 位移须 >30px），此类回归今后会被测试拦下。

### 手感（延续 v3.1，修复后真正生效）

- 距离自适应加速度（"磁铁式"，限刹车区外）+ 速度相关动态刹车，均已随积分行恢复而生效。
- 物理验证（`verify_physics.js`，测试基建同步修正 dt 一致性）：远端追鼠 2s 停稳于 58px；高速冲入末距离 41px、振荡 1 帧。

## [v3.1] - 2026-08-02

### 手感（真人实测反馈：不跟手、鼠标与箭头距离过远）

- **距离自适应加速度（"磁铁式"）**：`update()` 中加速度由固定值改为 `min(playerAccel + 距离×10, playerAccelMax=3200)`——鼠标大幅甩动时强力吸附快速追上，鼠标附近自动变细腻便于精控
- `playerMaxSpeed` 430 → 520（追鼠速度上限提高）
- `playerDamping` 0.9 → 0.7（落在复核建议区间 0.55–0.7；滑行更长、方向切换更灵敏）

## [v3] - 2026-08-02

### 新增

- **武器解锁改为跨局永久进度**（P0-2 绿点经济修复）：新增 `greensTotal` 跨局累计货币（localStorage `ttl_greens` 实时持久化）与已解锁武器列表持久化（`ttl_unlocked`）。解锁是永久进度（类似原版 Pocket Points），不再随单局重置；开局恢复存档并计算下一个待解锁武器。
  - 新增 `loadGreensTotal/saveGreensTotal/loadUnlocked/saveUnlocked` 存储函数（含 file:// 异常保护）
  - `checkUnlock` 改为递归连锁解锁（一次性跨过多个门槛），解锁即写入存档
  - HUD 解锁进度条显示累计货币；开始菜单与结算面板新增"武器货币 / 已解锁 N/10"显示

### 性能

- **红点互碰分离 O(n²) → 空间网格 O(n)**（P2-7）：按 48px 格子分桶（`Map<string, array>`，每帧重建 O(n)），只检查本格内部与右/下/右下/左下四个邻格，每对红点恰好检查一次；红点最大半径 17 < 半格宽 24，保证正确性。红点上限 450 不再构成每帧 10 万次比较。
- **粒子满员丢弃 O(1)**（P2-8）：`spawnParticle` 满 700 时直接丢弃新粒子，替代原 `shift()` 的 O(n) 全数组搬移。

### 清理

- 移除 `G.freezeTime` 死字段（v1 遗留、从未使用）、`G.redFlash` 重复定义
- 修复 Wave 扇形绘制代码块缩进错乱

### 测试

- `test_smoke.js` 新增跨局持久化断言：解锁写入 localStorage → 重开后已解锁武器与货币均恢复
- 全部通过（10 种武器触发、死亡流程、重开、跨局恢复）

## [v2] - 2026-08-02

### 新增

- **Wave 冲击波改为扇形扩散**：原版 Fandom 考证（Wave 页："Upon use, a wave bursts in the direction the player is facing, killing all dots in its path"）确认 Wave 应为**扇形圆弧扩散**，而非本项目 v1 的"一个小圆球直线飞"。现改为蓄力 0.5s 后朝面朝方向张开约 63° 扇形，半径从 20px 扩散至约 240px，扇形路径上的红点被扫中即灭。
  - 新增 `fanHit()` 命中判定函数（半径 + 张角双重校验，边界已验证）
  - 新增 `G.fans` 实体数组（更新 + 绘制 + 开局重置）
  - 移除 v1 的 wave 圆球逻辑与 `ms.wave` 复用标记（死代码清理）

### 修复

- **武器球数量溢出**（v1 bug）：收集武器球时既有同帧补刷、又有 `setTimeout(…, 800ms)` 延迟补刷，导致场上 orbs 可能超过设计值 3 个（连收 2 个实测变成 5 个）。已删除延迟补刷，只保留同帧"不足 3 个即补"逻辑。
- **非无敌状态撞冰冻红点直接死亡**（v1 bug）：碰撞判定原为"护盾 → 无敌（刺球/冰雕）→ 死亡"，导致普通玩家撞上自己冻住的冰雕红点直接死亡，与 GAME_DESIGN 文档"玩家撞碎 +10 分"不符。已把 `frozen` 提为碰撞最优先分支——**冰雕红点无论是否无敌都能撞碎**（+10 分，不重置连击）。
- **文档与代码多处不一致**（v1 遗留）：`ARCHITECTURE` 的 `M` 对象含未使用字段 `dirX/dirY`、`state` 枚举/orbs 补刷/碰撞流程描述与代码不符。已据代码修正文档。

### 性能

- 清理了 v1 遗留的 `ms.wave` 死代码分支（Wave 改 G.fans 后不再走导弹数组）。

### 修复

- **Burnicade 烈焰冲刺速度被钳制**（v1 bug）：冲刺设速 950 px/s，但被每帧 `playerMaxSpeed=430` 限速钳回，实测仅 430（强度缩水，GAME_DESIGN 标 950 而代码跑不出）。已改为**烈焰冲刺期（`aim=false`）放开常规限速**，实测冲刺达 950 px/s；瞄准期与冲刺结束后仍恢复 430 限速。

### 已知问题（未改动）

- 其余参见 `docs/GAME_DESIGN.md` §7「已知问题与后续迭代方向」。

### 测试

- `node test_smoke.js` 全部通过（含 10 种武器触发、死亡流程、重开）
- 新增验证（临时脚本运行后已清理）：
  - Wave 扇形命中：前置红点全部被扇形击杀，侧方/身后红点不误伤
  - orbs 数量恒定 3，连收不溢出
  - 非无敌撞冰冻红点存活且 +10 分；普通红点碰撞仍正常死亡
  - Burnicade 冲刺实测 950 px/s，冲刺后恢复 430 限速
